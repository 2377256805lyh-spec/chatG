# 害羞动作：密集实画姿势候选

本目录只交付素材；没有修改桌面程序、安装目录、声音、设置或其他动作。

- `cels/00.png` 至 `cels/21.png`：22 格有序双臂透明前景，576×624。首尾为原有中性手臂，原始身体使用 `../../layers/shy-body.png`。
- `metadata.json`：每格左右臂的原画来源、整层平移、是否变形、裁切多边形。
- `extract-cels.py`：生产切图工具。仅进行多边形/肤色范围裁切和原脸遮挡，不作关节旋转、网格蒙皮或光流补帧。需要 Pillow、NumPy。
- `preview.webp`：约 12 fps 的逐格审看，尚未加入正式播放的峰值停留/首尾等待。
- `cel-review.png`：完整人物逐格图；`arm-detail-0.png`、`arm-detail-1.png`：全部手臂的放大边界审看。
- `generation-prompt.md`、`additional-prompts.md`：使用内置 image_gen 的全部实际提示词。

原画图集来源：

| 文件 | 生成内容 | 最终使用情况 |
| --- | --- | --- |
| `atlas-candidate.png` | 24 格完整上半身 | 选用多个抬手、峰值和独立放下姿势；没有按原顺序播放 |
| `atlas-up-candidate.png` | 8 格抬手 | 选用第 3 格的较低抬手姿势 |
| `atlas-mid-candidate.png` | 8 格窄区间尝试 | 大多复用了端点，未选入最终时间表 |
| `atlas-bridge-candidate.png` | 4 格腰部到胸口的过渡 | 选用第 2、3、4 格 |
| `neck-candidate.png` | 单独绘制的颈侧中间姿势 | 选用左臂，补胸口到托腮之间的缺口 |

对齐只对每格整张原画作等比例缩放和平移，原始固定脸作为定位参照。生成图的脸、身体、脚和背景没有用于最终角色；只有手臂/手/袖子的限定前景被取出。峰值处原脸轮廓位于手的前面，手因此托在下颌外侧；没有把生成图的下颌色块、眼线或嘴线带进来。颈窝也明确排除在新前景之外。

已知限制：这 22 格是左右臂真实原画的有序组合，并不等于 22 张完全独立重画的全身。若干桥接手臂在抬起和放下阶段复用；峰值帧主要是布料/手部的小变化。各来源的线条粗细和袖褶仍有少量差异，不能承诺与专业逐帧手绘完全一致。这里审核的是实际原画和切图；正式运行时的节奏需由主程序时间表统一后再看。
