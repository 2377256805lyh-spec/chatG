# 小G · 使用说明

双击 `小G.exe` 打开白发小龙女。找不到人物时，可双击通知区域的小G图标，或右键图标选择找回。

| 操作 | 小G的反应 |
|---|---|
| 单击 | 短暂等待第二次点击后跳跃 |
| 双击 | 切换踮脚、思考、摇头、沮丧、等待、检查、困困打盹、灵光一闪 |
| 按住左右拖动 | 朝移动方向奔跑 |
| 鼠标靠近脑袋 | 轻轻转头注视 |
| 右键 | 放大、缩小、置顶、声音、音量和启动联动设置 |
| 自然待机 | 偶尔看看四周、踮脚、困困揉眼或思考 |

单击或双击各算一次互动，累计随机 5～7 次后显示一句短句，并播放同一句配音。共有 12 句，正在说话时不会被连续点击打断。

按住人物但停止移动时，会停止奔跑；松手后回到待机，再轻轻恢复鼠标注视。人物靠近屏幕顶部时，短句气泡会移到下方并翻转指向，避免盖住脑袋。长句优先在逗号处分行。

拖得慢时步频较慢，拖得快时步频会平滑加快。短暂停顿后继续拖动会接着当前步态，不再每次从头迈腿。跳跃途中双击或从菜单选择其他动作，会等落地后接上最近一次选择；拖动或选择“回到待机”仍立即生效。

转头计算与动画解压改为后台准备，快速绕着头部移动鼠标时，不会在界面回调里重新计算整张人物；动作切换后旧的转头结果不会重新盖回来。原画、动作帧数和配音素材保持不变。

本次进一步优先准备屏幕接下来几次实际需要的画面。解码慢一拍时，手臂、眼睑和装饰会按同一张实际显示画面的时间播放，跳跃位移也跟随实际姿势；奔跑循环暂时缺帧会保留末帧，减少突然闪回站立的情况。

右键人物或通知区域图标 → **待机陪伴** 可以开关 **自然待机**。默认每隔约 22～46 秒选择一个小动作，同一种行为不连续出现。鼠标靠近头部、点击、打开菜单或说话时会推迟；专注计时期间暂停自发动作。自发动作不会累计互动次数或自动说话，点击和拖动仍由你优先接管。

同一菜单选择 **让小G小憩一下**，她会缓缓闭眼、冒出淡紫色的 z。点击会先睁眼，再按原来的单击跳跃／双击动作规则响应，也可以从菜单选择 **叫醒小G**；拖动和手动播放动作同样可以结束小憩。空中请求小憩会等到落地。专注计时和语音开关保持有效，退出小G后不保留小憩状态。

[自然待机与小憩动态预览](previews/自然待机/预览.html)。预览缩短了等待与休息时间。

通知区域菜单的“全部设置和动作…”与人物右键菜单共用完整设置入口，方便调整大小、短句、声音与全部动作。

右键 → **专注陪伴** 可开始 25/50 分钟计时、查看剩余时间或提前结束。完成后只提醒一次，已有配音先说完再提醒；关闭语音就只显示气泡，关闭互动短句则改用通知区域文字提示，系统提示音沿用 Windows 的通知设置。重新开始会替换当前计时，退出小G不保留倒计时。无需网络或新增配音。

两个额外动作，也可通过右键 → 播放动作，或通知区域的小G菜单直接选择：

十一项动作的完整动态预览在 `previews/流畅度更新/预览.html`。

- **困困打盹（3.3 秒）**：抬手轻轻揉眼两下，闭眼打个小盹，放下手后睁眼恢复，伴随淡紫色的 z。
- **灵光一闪（3.1 秒）**：手从胸前抬起，在脸旁竖起食指，停留片刻后收指放手，亮起淡紫色灯泡和星光。

两个额外动作采用实画手臂、手指与袖子姿势，并在独立手臂层增加连续过渡。揉眼维持缓慢的两次往返，完整举指姿势和中性收尾仍停留；脸、脖子和服装底图保持固定，眨眼只渐进更新眼睛附近的小区域。动作素材按每秒 120 张制作，显示随屏幕实际绘制推进；预览与制作说明在 `previews/新增动作/`。

奔跑保留原有完整人物姿势，在每对相邻画面间增加小步过渡，每向 82 张；腿部交叉的原画问题尚未确认修复。踮脚增加到 217 张，思考增加到 529 张，所有原采样逐张保留。摇头保持已经确认的轻柔节奏，沮丧、等待和检查沿用原有 120Hz 画面，统一改善播放时序和预读；等待与检查的部分旧过渡仍有轮廓重叠。跳跃起跳与落地之间的位置已连续衔接。

本版只使用确认后的清澈软萌去沙声线。声音、动作和短句均在本机播放，不在线生成、不消耗聊天额度；制作时使用的语音模型无需安装。

位置、大小、置顶、声音和音量等设置保存在程序旁的 `settings.json`。更新时退出旧程序、替换 `小G.exe`，保留原来的设置文件即可。语音资料放在 `assets/voice/` 中供后续重制，程序本身已内置音频。

显示器或任务栏工作区变化后，小G会自动回到屏幕可见范围。从菜单选择动作会取消尚未确认的单击，避免动作被意外跳跃打断。

在右键菜单开启“随桌面 Codex 启动”后，隐藏等待程序会在桌面 Codex 打开时启动小G。手动退出小G后，同一次 Codex 打开期间不会反复拉起；可在同一菜单取消联动。

源码、编译方法和素材署名见 [GitHub 项目](https://github.com/2377256805lyh-spec/chatG)。本项目是个人学习用途的非官方同人创作，与 OpenAI 等品牌方没有官方关联。
