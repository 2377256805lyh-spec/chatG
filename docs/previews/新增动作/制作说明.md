# 新增动作 · 2026-10-21

| 动作 | 时长 | 表现 |
| --- | --- | --- |
| 困困打盹 | 3.3 秒 | 抬手揉眼，以三张相邻的小幅姿势缓慢轻揉两次，放下手后慢慢醒来，伴随淡紫色 z |
| 灵光一闪 | 3.1 秒 | 手从胸前抬起，竖起食指，停留后收指放手，灯泡和星光亮起 |

从小G右键菜单的「播放动作」或通知区域菜单直接选择；也已加入双击轮换。

人物沿用当前 576×624 高清原画及已使用的眨眼画面。这版把六张姿势之间的关节蒙皮补帧改为更密的实画原画：独立画出抬手、手指变化、袖口滞后及收手过程，再分离双臂或单臂逐格播放。运动阶段使用不同曝光时长，过渡姿势不再连续长停；完整表意姿势与中性收尾才停留，揉眼使用实际原画往返。唯一画面数以 `制作清单.json` 和帧包清单为准，重复曝光不算新绘制姿势。

脸、脖子、衣领与服装底图不参与肢体插值；仅在旧手臂遮挡的区域补出底图。身体、眨眼、肢体前景、矢量装饰分别绘制，揉眼的手始终位于眼睛前方，眨眼时不会被眼部图层擦掉。原图中的手臂消失后，露出的头发、翅膀和腰饰来自专门制作的遮挡底图。

本目录的 PNG 为程序绘制结果；WebP 是便于查看的 384×416、每秒 60 帧动态预览，不代表程序降低了人物分辨率或更新频率。动画可在浏览器打开。

原有动作、语音、语录、设置文件和 Codex 启动联动均沿用。此次不涉及此前尚未解决的奔跑交叉帧问题。

目前的生产打包入口为 `scripts/make-painted-gestures.py`，时间表在 `assets/extra-gestures/painted/sequence.json`。真实手绘图集、对齐图、裁切边界、肢体层及内置 image_gen 的完整提示词保存在 `assets/extra-gestures/painted/`。整层平移、镜像或统一比例仅用于匹配原人物肩部与大小，不对关节、脸或脖子产生变形。`src/ExtraGestureArtwork.cs` 和 `src/ExtraActions.cs` 负责合成，`scripts/export-extra-actions.ps1` 使用同一套绘制函数导出完整 PNG 序列。

实现前参考了 [Shijima-Qt 的桌面角色与绘制实现](https://github.com/pixelomer/Shijima-Qt/blob/main/ShijimaWidget.cc)；本次没有复制该项目代码或引入其运行依赖。

害羞晃晃已从轮换、菜单和运行时帧包移除；原画保留作历史素材。打盹抬手阶段增加0.1秒，揉眼与收手阶段保持；灵光一闪的完整举指姿势增加0.3秒停留，星光同步延长。
