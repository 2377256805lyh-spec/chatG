# 小G

一个陪你学习的白发龙娘 Q 版 Windows 桌面挂件，支持动作互动、鼠标注视、花饰短句气泡和本地角色配音。

## 互动方式

| 操作 | 反应 |
|---|---|
| 单击人物 | 约 280 毫秒内没有第二次点击时起跳 |
| 双击人物 | 依次切换踮脚、思考、摇头、沮丧、等待、检查、困困打盹、灵光一闪 |
| 按住左右拖动 | 朝拖动方向奔跑，松手停止 |
| 鼠标靠近头部 | 轻轻转头注视；离开时平顺回正 |
| 累计互动 5～7 次 | 随机显示一句短句，并播放对应配音 |
| 右键人物或通知区域图标 | 调整大小、置顶、语音、音量、启动联动和动作 |
| 自然陪伴 | 偶尔看看四周、踮脚、揉眼或思考，完整小动作之间留出安静时间 |
| 右键 → 陪伴模式 → 休息 | 缓缓闭眼，伴随淡紫色的 z；切回陪伴或点击即可叫醒 |

单击和双击各算一次互动，拖动不计数。气泡里的文字和配音对应，当前语录不会被连续点击打断。音量提供 25%、55%、80% 三档，只影响小G。

现用配音采用确认后的清澈软萌声线，仅保留这一款。所有配音提前生成并嵌入程序；日常显示、互动、语录和声音播放均在本机完成，不发送聊天请求、不消耗模型额度。

动作使用高清原画和预制过渡画面，转头另有细节位移数据；思考将手臂与身体分层，摇头保留颈部和衣领。播放跟随 WPF 的屏幕呈现时间推进，去掉叠加的固定频率取整；素材大多为每秒 120 张，奔跑约为每秒 120.59 张。实际显示帧率取决于屏幕刷新率和系统负载。

困困打盹与灵光一闪使用逐格实画的手臂和袖子，固定脸、脖子与身体。打盹抬手稍慢，揉眼轻揉两次；灵光一闪举指冒星光时多停留约 0.3 秒。害羞晃晃已移除，原画只作为历史制作资料保留。摇头先轻轻起势，左右摆幅逐渐收小，最后缓缓回正；下巴随转向变化，衣领保持稳定。奔跑沿用原有整个人物姿势，交叉步观感仍待后续改进。

踮脚、思考和左右奔跑保留原来每一张采样，在相邻画面之间增加受限的小步过渡；分别为 217、529 和每向 82 张。两种新动作的独立手臂层也增加连续过渡，保留慢揉眼和举指停留。眨眼只渐进更新眼部矩形。跳跃起跳与落地的整体位置连续衔接。检查和等待部分旧原画过渡仍有轮廓重叠，增加播放采样不能完全修复这类美术问题。

正式运行仅准备待机、眨眼和转头必需的原画，其他动作从帧包按需读取；解压使用独立的可复用缓冲区，缓存优先保留最近播放的画面。选择动作、按下人物及切换奔跑方向时预先准备画面，后台预读覆盖未来约 0.4 秒；奔跑循环的各帧按完整曝光时间播放，避免首尾停留不均。

实时播放的转头计算和帧包解压在后台执行，界面只取已就绪的图。转头仅保留最新待算方向，动作切换会使旧转头结果失效；解码落后时优先取本段播放已走过的最近就绪画面，不倒播、不串动作，也不取未来帧。生产导出器仍同步读取每张素材。

拖动速度会平滑影响步频，停顿会减速，继续拖动沿用本次拖动的步态相位，避免反复从前半步起跑。跳跃途中请求其他动作时，仅保留最近一次请求，落地后接上；拖动和手动回到待机仍可立即打断。系统较长停顿后按真实经过时间恢复动作，不让动作时钟落后于语录与声音。

预读会先准备接下来几次屏幕呈现实际需要的采样，再填补中间画面。解码暂时落后时，困困打盹与灵光一闪的眼睑、身体和装饰沿用实际手臂画面的时间；跳跃位移也跟随已显示的姿势。奔跑自然跨过循环边界时，短暂缺帧会保持上一圈末帧，避免突然闪成站立图。这些播放改进没有添加帧或拉伸人物。

动作结束和拖动松手后统一恢复待机，再柔和地恢复鼠标注视。按住人物但停止移动时会停止奔跑；拖动意外中断也会清理拖动状态。人物靠近屏幕顶部时，语录气泡改到下方显示，指向同步翻转；长句优先按逗号分行，无逗号时分成相近的两行。

## 下载与编译

使用 64 位 Windows，需要 Git、Git LFS（Git Large File Storage，Git 大文件存储），以及 Windows 的 .NET Framework C# 编译器与 WPF（Windows Presentation Foundation，Windows 界面绘制框架）。已有素材可直接编译，无需语音模型或 Python。

```powershell
git clone https://github.com/2377256805lyh-spec/chatG.git
Set-Location chatG
git lfs install --local
git lfs pull
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\小G.exe
```

构建会校验动作帧包、新动作身体底图、转头、思考分层和配音素材；配音还会核对文本、顺序和文件哈希。随后将素材嵌入根目录的 `小G.exe`。主动画帧包为数百 MB，使用 Git LFS 保存；若文件只有几行文字，请先运行 `git lfs pull`。

编译出的程序不提交到源码仓库。便携运行只需 `小G.exe`；更新时退出旧程序、替换可执行文件，并保留原来的 `settings.json`。

## 设置与启动

右键人物或通知区域图标 → **陪伴模式**，统一选择以下三项，当前只会选中一项：

| 模式 | 表现 |
|---|---|
| 自然陪伴 | 偶尔看看四周、踮脚、揉眼或思考，鼠标靠近时优先看你 |
| 安静陪伴 | 保留眨眼和鼠标注视，暂停自发小动作 |
| 休息 | 慢慢闭眼小憩，两枚淡紫色的 z 缓缓飘起 |

自然陪伴默认开启。轻动作间隔通常约 22～46 秒，完整的踮脚、揉眼、思考至少间隔 70 秒；连续三分钟没有靠近头部或主动互动时，间隔放宽到约 32～58 秒，更多地安静看看四周。完整动作避免连续重复，左右张望交替。鼠标靠近脑袋、正在点击、菜单打开或正在说话时推迟自发动作；自发动作不计入互动次数，也不会自动触发配音。

从休息切回任一陪伴模式，会从当前眼睑位置连续睁眼，清除休息装饰，再恢复注视和眨眼；半闭眼时反复改选也接着当前画面过渡。点击、拖动、手动播放动作也能叫醒，单击跳跃、双击动作的规则保留。跳跃时请求休息会等落地，落地前切回陪伴可以取消。记住自然／安静陪伴的选择，休息仅本次有效，退出后不会自动保持闭眼。

同一菜单 → **专注计时**，可以开始 25 或 50 分钟计时、查看剩余时间，也可以提前结束。开始计时会叫醒小G，计时期间暂停自发动作；完成后恢复原来的自然或安静陪伴，叫醒并用已有休息语录提醒一次，当前正在说话就等它说完。关闭角色语音时只显示气泡；关闭互动短句时改用通知区域文字提醒，系统提示音沿用 Windows 的通知设置。休息与模式切换不取消计时或修改声音开关；计时仅在本机进行，退出小G会结束本次计时，重新开始会替换上一轮。

窗口位置、大小、置顶、语音开关、音量等保存在程序旁的 `settings.json`，该个人设置文件不提交到仓库。找不到人物时，可从通知区域图标选择找回，或双击图标将人物移回主屏幕。

通知区域菜单的“全部设置和动作…”可打开人物右键使用的完整菜单，调整大小、短句、音量或选择任一动作。

拔插显示器、调整分辨率或任务栏工作区后，人物会自动收回当前屏幕的可见范围。主动从菜单播放动作时，会取消尚未确认的单击，避免刚选的动作被跳跃覆盖。

在右键菜单开启“随桌面 Codex 启动”后，程序在当前用户的 Windows 启动文件夹创建快捷方式，隐藏等待进程检测到桌面 Codex 窗口后打开小G。手动退出小G后，不会在同一次 Codex 打开期间反复拉起。可在同一菜单关闭此功能。

## 项目结构

| 路径 | 内容 |
|---|---|
| `src/` | 15 个 C# 源文件与应用清单 |
| `assets/artwork/` | 程序使用的高清动作图与思考分层图 |
| `assets/gaze/` | 已对齐的转头原画和定位点 |
| `assets/thinking/` | 思考原画、遮挡底图与手臂轮廓 |
| `assets/voice/` | 唯一正式声线、12 段配音及制作记录 |
| `assets/animation-frames.zip` | 预制动画帧包，使用 Git LFS |
| `assets/extra-gestures/` | 新动作的原画、透明肢体层、提示词与曝光时间表 |
| `assets/extra-gestures.zip` | 困困打盹与灵光一闪的透明肢体帧包 |
| `scripts/` | 可选的配音、转头、动作和分层制作入口 |
| `docs/` | 素材来源、第三方许可和动态预览 |
| `build.ps1` | Windows 构建入口 |

## 可选的素材重制

普通编译和日常运行不需要这些制作环境。

- `scripts/make-voice.py`：使用保留的 `assets/voice/reference.wav` 和声音设计记录制作全部语录。需要 Qwen3-TTS 与兼容模型环境，具体依赖见脚本开头。现用声线以确认样本的自然节奏为准，重制时使用 `--tempo 1`；调整节奏才需要 FFmpeg。
- `scripts/make-gaze.py`：从 `assets/gaze/` 生成转头位移文件和校验清单。
- `scripts/make-thinking-layers.py`：从 `assets/thinking/` 生成手臂和身体遮挡底图。
- `scripts/make-painted-gestures.py`：按 `assets/extra-gestures/painted/sequence.json` 制作两种新动作的手臂过渡，需要 NumPy、Pillow、OpenCV；脸、脖子和身体底图不参与手臂插值。
- `scripts/export-extra-actions.ps1`：从编译好的程序导出与实际绘制一致的完整 PNG 动作序列；用 `-AssemblyPath .\小G.exe -Output <输出目录>` 指定输入输出。
- `scripts/export-animation-poses.ps1 -ShakeOnly`：导出 313 张摇头完整画面；交给 `scripts/make-animation.py --shake-frames <画面目录>` 单独替换摇头，其余动作按原压缩记录保留。这条打包路径只需 NumPy 和 Pillow。
- `scripts/make-animation.py --smooth-existing`：在现有 60Hz 动作的原始采样间增加小步画面；位移和画面变化超限时使用相邻画面的保守过渡，不做五官定位或重建透明轮廓。原有 120Hz 动作保持不变。需指定不同的 `--oldpack`、`--output` 和 `--preview` 路径。
- `scripts/export-animation-poses.ps1 -AllActions`：按正式动作采样函数导出九项完整姿势序列，`-FramesPerSecond` 可设定制作预览的采样频率。

转头与思考分层制作需要 NumPy、Pillow 与 OpenCV。`make-extra-gestures.py` 是历史六姿势制作入口，其 `frames` 阶段不能覆盖当前实画帧包。声音制作和素材重制完成后需重新构建程序。
